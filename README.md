# Exercícios da Apostila Métodos em Java

Este repositório reúne minhas resoluções dos exercícios da apostila Métodos em Java.

## Conteúdos praticados

- Declaração e chamada de métodos
- Passagem de argumentos e uso de parâmetros
- Métodos com `void` e métodos que retornam valores
- Divisão de um problema em métodos menores

## Como executar

1. No GitHub, clique em **Code → Download ZIP** e extraia os arquivos.
2. Abra a pasta do projeto no IntelliJ IDEA.
3. Abra a classe do exercício e clique em **Run** ao lado do método `main`.
